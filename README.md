# Financial Incentives and India's Janani Suraksha Yojana

In-class paper presentation for **Health Economics (ECO-3650), Ashoka University**.

Paper presented: Powell-Jackson, Mazumdar & Mills (2015), "Financial Incentives in
Health: New Evidence from India's Janani Suraksha Yojana," *Journal of Health
Economics* 43, 154–169.

## Contents
- `jsy_presentation.pdf` — the slides (Beamer, Madrid theme)
- `jsy_presentation.tex` — LaTeX source
- `crop_*.png` — figures and tables cropped from the paper, used by the source
